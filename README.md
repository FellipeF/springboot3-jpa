## Architecture

This project follows a structured architecture with separate logical layers:

- **Application Layer**: The entry point for starting the application.
- **Resource Layer (REST API)**: Exposes endpoints to handle HTTP requests, utilizing RESTful principles through controllers.
- **Service Layer**: Manages business logic and orchestrates the flow of information between the Resource and Data Access layers.
- **Data Access Layer (Repository)**: Interacts directly with the database, encapsulating data access logic.
- **Entities**: Represents domain objects and maps to database tables.
